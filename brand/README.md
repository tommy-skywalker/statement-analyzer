# Statement Analyzer · Brand Kit

Identity: black `#0a0a0a` / white, terminal green accent `#4ade80` (dark) / `#16a34a` (light),
red `#f0574f` for money-out. Type: Helvetica/Arial (brand), Menlo/monospace (terminal).

| File | Use | Export size |
|---|---|---|
| `logo-mark.svg` | App icon, avatar, watermark | 512×512 / 1024×1024 |
| `logo-horizontal.svg` | Light backgrounds, docs, invoices | any |
| `logo-horizontal-dark.svg` | Dark backgrounds, video outros | any |
| `og-cover.svg` | Link-preview card (already live at `/og.png`) | 1200×630 |
| `x-header.svg` | X/Twitter profile header | 1500×500 |
| `ig-post.svg` | Instagram launch post | 1080×1080 |
| `flyer-a4.svg` | Print flyer / poster | 2480×3508 (A4 @300dpi) |
| `../static/favicon.svg` | Browser tab icon (served at `/favicon.svg`) | — |

## Exporting SVG → PNG
Any of these work:
- Open the SVG in Chrome → screenshot, or
- [Figma](https://figma.com): drag SVG in → Export PNG @2x, or
- `npx svgexport in.svg out.png 2x`, or
- Online: svgtopng.com

Print shops accept the flyer SVG directly or a 300dpi PNG export.
